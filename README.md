# Gerador de PDF Cyber

Este é um gerador automático de PDFs a partir de códigos de anúncios do Mercado Livre.

## Funcionalidades
- Leitura de planilhas Excel com códigos MLB
- Geração em lote de PDFs dos anúncios
- Registro visual com ícone e interface em etapas
- Exportação de relatório com status
- Atualizações automáticas via GitHub (em breve)

## Como usar
1. Execute `GerarPDF.py`
2. Informe o token, selecione o Excel e a pasta de saída
3. Aguarde a geração dos arquivos
